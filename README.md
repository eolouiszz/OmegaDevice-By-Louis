## Overview

ΩMEGA DEVICE is an experimental Luau project designed to explore local instance manipulation and the behavior of the Roblox client under aggressive environment cleanup operations.

The project combines instance removal, interface manipulation, visual environment changes, and experiments involving character and camera objects.

## Features

- Local instance removal and environment cleanup
- CoreGui visibility manipulation
- Lighting and sky modifications
- Character and camera handling experiments
- Console logging and execution status messages
- Client execution and scheduling behavior experiments

## Technical Notes

ΩMEGA DEVICE operates within the permissions and limitations of its execution context. Client-side changes do not automatically replicate to the server, and destroying local instances does not guarantee permanent changes to the experience.

Some operations may interrupt normal gameplay, affect camera behavior, or prevent other scheduled tasks from executing as expected.
